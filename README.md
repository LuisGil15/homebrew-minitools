# Homebrew Cask for MiniTools

This tap distributes the signed and notarized builds published by the
[MiniTools distribution repository](https://github.com/LuisGil15/MiniTools).

## Install

```bash
brew install --cask LuisGil15/minitools/minitools
```

## Update

```bash
brew update
brew upgrade --cask minitools
```

## Uninstall

```bash
brew uninstall --cask minitools
```

MiniTools requires macOS Ventura 13 or later and an Apple silicon Mac.
